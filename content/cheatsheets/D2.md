# D2 — Secure storage, databases, and networking (25–30%)

## D2.1 Storage — [D2.1.1](../objective/D2.1.1.html) · [D2.1.2](../objective/D2.1.2.html) · [D2.1.3](../objective/D2.1.3.html) · [D2.1.4](../objective/D2.1.4.html)

| Account switch (`Settings > Configuration`) | Default | Set to |
|---|---|---|
| Secure transfer required | on (new) | on |
| Minimum TLS | 1.2 portal; property may be unset via CLI/ARM, but ==!service refuses TLS 1.0/1.1 on all accounts since 3 Feb 2026== | set `TLS1_2` + Policy (==!1.3 not selectable==) |
| Allow Blob anonymous access | off (new) | off — beats every container level |
| Allow storage account key access | ==!null = allowed== | Disabled, after migrating callers |
| Cross-tenant replication | off (new) | off |
| Infrastructure encryption | off | ==!creation only== |

- **Encryption at rest** always on (AES-256, Microsoft-managed key). **CMK**: RSA key, vault with ==@soft delete + purge protection==, identity with get/wrapkey/unwrapkey; ==@user-assigned== identity at account creation. Customer-*provided* key = per-request, never stored. Encryption scopes = per container/blob key.
- **Disable Shared Key** → account key, service SAS, account SAS get 403; ==+user delegation SAS + Entra keep working==. Find callers: Transactions metric split by authentication type. Policy *Storage accounts should prevent shared key access*: Audit → Deny (==!Deny doesn't fix existing==).
- **Firewall**: rules only bite when default action = Deny (*selected networks*). Data plane only.

| Rule type | Allows | Limit | Gotcha |
|---|---|---|---|
| VNet rule | subnet with `Microsoft.Storage` (same region) or `.Global` endpoint | 400 | any tenant; only one endpoint type per subnet |
| IP rule | public IPv4 CIDR | 400 | ==!no RFC 1918, no /31 /32, no same-region clients== |
| Resource instance | one named resource via its managed identity + RBAC role | 200 | same tenant |
| Exceptions | trusted services (Backup, Monitor, Event Grid…), Logging, Metrics | — | ==!not "all of Azure"== |

- Private endpoint traffic ==+bypasses the firewall==; creating one ==!does not close the public endpoint==.
- **Access by signature**:

| | Signed by | Stored access policy | Survives Shared Key off | Revoke |
|---|---|---|---|---|
| Entra token + data role | Entra ID | — | ✓ | remove role |
| ==+User delegation SAS== | user delegation key (≤ ==@7 days==) | ==!no== | ✓ | `revoke-delegation-keys` / remove role |
| Service SAS | account key | ==+yes (max 5 per container)== | ✗ | ==+delete policy== / rotate key |
| Account SAS | account key | no | ✗ | rotate key |

- ==@ABAC conditions== = attribute test (e.g. blob tag) on a data role; ==!no effect on management Actions==. SAS expiration policy: Log (default) or Block.
- **Defender for Storage** (per account): activity monitoring (always), ==@malware scanning== on upload (per GB, default cap ==@10,000 GB/account/month==, alerts at 75%/100%, ==!then uploads go unscanned==; blobs ≤ 50 GB; result in blob index tags), on-demand scan (no cap), ==@sensitive data threat detection== (re-prioritises, ==!no new alerts==, free). Enable at subscription (covers new accounts); per-account **override** for own cap. ==!Deleting the Event Grid system topic stops scanning.== Classic per-transaction plan: no new enablement after 5 Feb 2025.

## D2.2 Azure SQL — [D2.2.1](../objective/D2.2.1.html) · [D2.2.2](../objective/D2.2.2.html) · [D2.2.3](../objective/D2.2.3.html)

| Layer | Control | Key fact |
|---|---|---|
| Who | Entra admin (one user/group) → ==@Entra-only auth== | Entra admin first; disables every SQL login; apps = managed identity + `CREATE USER … FROM EXTERNAL PROVIDER` |
| From where | DB-level IP rule (==@T-SQL only, checked first==), server rule (max 256), VNet rule, private endpoint, public access Disable | ==!Allow Azure services = 0.0.0.0 = every customer's Azure== |
| MI network | subnet delegated to `Microsoft.Sql/managedInstances`; ==!no IP firewall== → NSG | public endpoint port ==@3342==, off by default |
| In transit | min TLS ==@1.2== (1.0/1.1 retired 31 Aug 2025) | can't return to "no minimum"; error 47072 |
| At rest | ==@TDE== on by default; CMK protector RSA 2048/3072 | purge protection; identity needs **Key Vault Crypto Service Encryption User**; key revoked → DB **Inaccessible** |
| From DBAs | ==@Always Encrypted== (client driver) | deterministic = equality only; enclaves add range/pattern; SGX ends 31 Oct 2027 |
| What users see | DDM (masks results, ==!not a boundary==; admins see all), RLS (filter + block predicates), Ledger (tamper-evident) | `UNMASK` grants real values |

**Auditing**: defaults `BATCH_COMPLETED_GROUP` + successful + failed authentication groups. Server audit covers all DBs; DB audit runs ==!alongside it (duplicates)==.

| Destination | Use | Note |
|---|---|---|
| Storage (`.xel`) | WORM archive | managed identity + Storage Blob Data Contributor; retention 0 = unlimited; WORM interval must be ==!shorter== than SQL retention |
| Log Analytics (`AzureDiagnostics`, `SQLSecurityAuditEvents`) | KQL, Sentinel | via a diagnostic setting — ==!delete it and auditing silently stops== |
| Event Hubs | live SIEM feed | no retention |

MI: T-SQL `CREATE SERVER AUDIT … TO URL` (SAS credential) or `TO EXTERNAL_MONITOR` ==+plus diagnostic setting==. Support-operations auditing: separate toggle/audit (`DevOpsOperationsAudit`). Auditing is best-effort.

**Defender for Databases** (Databases plan = all four subplans; Select types to pick):

| Subplan | Covers | VA |
|---|---|---|
| Azure SQL Databases | SQL DB, SQL MI, Synapse dedicated pools | ✓ (express) |
| SQL Servers on Machines | SQL on Azure VMs + ==@Arc== (on-prem/AWS/GCP); extension, Owner deploys | ✓ |
| Open-source relational | PostgreSQL/MySQL ==@flexible server==, Amazon RDS | ==!✗; not on VMs== |
| Cosmos DB | ==!NoSQL API only== | ✗ |

VA **express** config = results kept by Defender, no storage account (classic needs your storage; classic APIs retire 16 Aug 2027). Baseline = accept a finding.

## D2.3 Network — [D2.3.1](../objective/D2.3.1.html) → [D2.3.9](../objective/D2.3.9.html)

**NSG/ASG** ([D2.3.1](../objective/D2.3.1.html)): priority 100–4096, ==@lower wins==, first match stops; 2,000 rules; ==@stateful==, new flows only. Inbound: subnet → NIC; outbound: NIC → subnet; ==!both must allow==.

| Default rule | Prio | Effect |
|---|---|---|
| AllowVNetInBound / AllowVnetOutBound | 65000 | ==!whole VNet + peers + on-prem allowed== |
| AllowAzureLoadBalancerInBound | 65001 | probes (168.63.129.16) |
| AllowInternetOutBound | 65001 | ==!outbound internet open== |
| DenyAllInbound / DenyAllOutBound | 65500 | deny |

ASG = NIC group used in rules; ==!same VNet only==; 20 per IP config. No custom service tags. ==!No NSG on GatewaySubnet.== New flow logs: ==+VNet flow logs== (NSG flow logs: none new since 30 Jun 2025, retire 30 Sep 2027).

**AVNM** ([D2.3.2](../objective/D2.3.2.html)): network manager (scope + features) → network group (static or ==@Azure Policy `addToNetworkGroup`==) → security admin config (==!one per region==) → rule collection → rule (prio ==@1–4096==) → ==!deploy== (goal state; deploy *None* to clear). Evaluated ==@before NSGs==. **Deny** stops; **Always Allow** delivers, skips NSGs; **Allow** ==!hands on to NSGs==. Skipped: MI/Databricks VNets, gateway/Firewall/Bastion subnets. Higher-scope manager wins conflicts.

**Virtual WAN** ([D2.3.3](../objective/D2.3.3.html)): ==!Basic = S2S only, no firewall==; upgrade to Standard (no downgrade). **Secured virtual hub** = Azure Firewall (Firewall Policy) in hub via Firewall Manager; ==+no AzureFirewallSubnet, no UDRs==. ==@Routing intent== (Private traffic + Internet traffic policies) is required to inspect inter-hub and branch-to-branch; on ==every hub==; no custom route tables. 0.0.0.0/0 ==!doesn't cross hubs==. Internet: Direct Access (default) or Forced Tunnel.

**VPN** ([D2.3.4](../objective/D2.3.4.html)): AZ SKUs (VpnGw1AZ–5AZ), Standard public IP. ==!Basic: no OpenVPN → no Entra auth, no RADIUS, no custom IPsec, no BGP/active-active.== Custom IPsec/IKE policy per **S2S/VNet-to-VNet connection**, all parameters, only those accepted (IKEv2, AES256, SHA256, DHGroup14, PFS). P2S auth: certificate (no MFA), RADIUS, ==+Entra ID (OpenVPN + Azure VPN Client only; MFA/CA)==. S2S forced tunnel = VM internet → on-prem; P2S forced tunnel = client traffic → Azure. ==!ExpressRoute isn't encrypted== → MACsec (Direct) or IPsec over private peering.

**Entra Private Access** ([D2.3.5](../objective/D2.3.5.html), Entra admin center): GSA client → Microsoft edge → ==@outbound-only connector== (Windows Server 2016+, 443/80) → app. **Quick Access** = transition; ==+per-app access== = Zero Trust end state, per-app Conditional Access. Direct assignment, ==!no nested groups==; ≤ 15 min. Licence: ==!P1 not enough== → Private Access or Entra Suite.

**Private endpoint** ([D2.3.6](../objective/D2.3.6.html)): NIC + private IP for ==@one resource + one sub-resource== (`blob`, `file`, `dfs` needs `blob` too, `sqlServer`, `vault`). Same region/subscription as its VNet. Approval auto or manual (==!only Approved carries traffic==). DNS: `privatelink.*` zone + VNet link + zone group; KV zone ==@privatelink.vaultcore.azure.net==. On-prem: conditional forwarder for the ==+public zone== → DNS Private Resolver inbound endpoint. Network policies ==!off by default== (NSG/UDR ignored); /32 route beats 0.0.0.0/0. Then disable public access. Policy: Audit → remediate → Deny.

**Private Link service** ([D2.3.7](../objective/D2.3.7.html)): provider side behind ==@Standard internal LB== (NIC backend pool), same region; consumers anywhere via private endpoint; ==+NAT IPs solve overlap== (≤ 8); alias ==!not a secret==; visibility (RBAC only / subscription / anyone with alias) ≠ auto-approval; real client IP via ==@TCP Proxy v2==; NAT subnet `privateLinkServiceNetworkPolicies` Disabled.

**Azure Firewall** ([D2.3.8](../objective/D2.3.8.html)): order ==@threat intel → DNAT → network → application → infrastructure → deny==.

| | Basic | Standard | Premium |
|---|---|---|---|
| App rule FQDN (SNI) | ✓ | ✓ | ✓ |
| Threat intel | ==!alert only== | alert + deny | alert + deny |
| DNS proxy, network-rule FQDNs, web categories | — | ✓ | ✓ |
| TLS inspection, IDPS, URL path | — | — | ==+✓== |

`AzureFirewallSubnet` ≥ /26 + spoke UDR `0.0.0.0/0 → VirtualAppliance` (==!no route, no inspection==). Firewall Policy: parent rule collection groups ==!always win==; DNAT not inherited. TI default ==!Alert==. Forced tunnelling needs Management NIC, ==!no DNAT==. App rules ==!never inbound== → WAF. TLS inspection: intermediate CA in Key Vault, user-assigned identity Get/List secrets.

**Network Watcher** ([D2.3.9](../objective/D2.3.9.html)): rule list → **effective security rules** (NSGs + AVNM); verdict + rule name for TCP/UDP → ==+IP flow verify== (no agent); ICMP/VMSS/service tag → **NSG diagnostics**; routing → **next hop** (None = dropped); live reachability/DNS/guest firewall → **connection troubleshoot**; payload → **packet capture** (==!extension==, 5 h default); history → **VNet flow logs** (Standard storage, same region) + traffic analytics (`NTANetAnalytics`, 60/10 min). ==!Nothing shown for private endpoint NICs.==

## Traps → truth

1. Service endpoint hides the public endpoint → ==!no==; ==+private endpoint + public access Disabled==.
2. Private endpoint created = public closed → ==!no==, disable public access last.
3. VMs still hit public IP → missing ==+private DNS zone / VNet link==.
4. On-prem forwarder targets `privatelink.` zone → ==+public zone name==.
5. Private-range IP rule on storage → invalid; allow the public NAT IP.
6. Contributor reads blobs via Entra → ==!no==; needs a data role.
7. Stored access policy on user delegation SAS → ==!unsupported==.
8. Revoke one vendor's service SAS → ==+delete the stored access policy==.
9. Malware cap reached → uploads continue ==!unscanned==.
10. DBAs must not see SSNs → ==+Always Encrypted==, not DDM or TDE.
11. Partner IP to one SQL database → ==+database-level rule (T-SQL)==.
12. SQL MI IP firewall → none; NSG.
13. MI Entra admin fails → identity lacks ==+Directory Readers==.
14. Server + DB audit = override → ==!duplicates==.
15. PostgreSQL on a VM → ==!not covered== by open-source plan.
16. Subnets isolate → ==!AllowVNetInBound==; add Deny rules.
17. Deleting an NSG rule cuts the session → ==!new flows only==.
18. NSG Allow beats admin Deny → ==!never==; plain admin Allow still defers to NSGs.
19. Admin config created = live → ==!deploy it==.
20. Firewall in VWAN hub secures everything → ==+add routing intent==.
21. Entra P2S on Basic or IKEv2 → ==!impossible==.
22. Connector needs inbound 443 → ==!outbound only==.
23. PLS behind Basic/public LB or App Gateway → ==+Standard internal LB==.
24. Network rule allows 443 Any, app rule denies site → ==!allowed==.
25. TI "enabled by default" blocks → ==!Alert only==.
26. Which rule blocks RDP → ==+IP flow verify==; ICMP → NSG diagnostics.
27. New NSG flow log → ==+VNet flow log==.
