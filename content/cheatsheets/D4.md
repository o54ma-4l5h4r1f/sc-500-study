**Compliance.** Default: Azure = ==@MCSB==; AWS = MCSB + ==@AWS Foundational Security Best Practices==; GCP = MCSB + ==@GCP Default==. International/EU frameworks (ISO 27001, PCI DSS, NIST, CIS Controls, SOC, HITRUST, GDPR, NIS2, DORA, EU AI Act) cover all three clouds; each cloud has its own **CIS Foundations**; ==!HIPAA and FedRAMP are Azure-only==. Assign at MG / AWS management account / GCP organization. Standard with no resources in scope ==!doesn't appear==. First results ≤ 12 h. Own baseline = **custom standard** (Owner); KQL custom recommendations = all clouds + ==!Defender CSPM==. Trend = **Compliance over time** workbook; point-in-time = **Download report**. Feeds Purview Compliance Manager.

- Scope: subscription/connector = default. Per resource: Servers P1 (enable), ==!P2 disable only==, Storage, Azure SQL, OSS DBs. Workspace: Servers, SQL on machines. MG: Azure Policy ==@deployIfNotExists== + remediation task, or Defender portal plan management (preview, ==@Enforce and lock==, DWU billing, drops resource-level settings, Azure only).
- ==!One Servers plan per subscription.== P1 dev + P2 prod → separate subscriptions.
- 30-day trial per plan. Disabling a plan ==!leaves extensions== (they stop collecting). Verify with **Coverage workbook**.

| Connector | AWS | GCP |

- On-premises: ==!no connector== — Arc (service principal with **Azure Connected Machine Onboarding**, outbound 443) or MDE direct onboarding (P1 features + premium MDVM). JIT and agentless ==!don't reach on-prem Arc==. Stale Arc for deleted EC2/GCP VMs removed after 7 days.

EASM = Azure resource, ==@30-day trial==, Contributor creates, ==!no cross-tenant/Lighthouse==. Seeds: org names, domains, IP blocks, hosts, email contacts, ASNs, WHOIS — ==!no private IPs==. ## D4.2 Sentinel collection

Pages: [4.2.1](../objective/D4.2.1.html) workspaces · [4.2.2](../objective/D4.2.2.html) roles · [4.2.3](../objective/D4.2.3.html) content hub · [4.2.4](../objective/D4.2.4.html) connectors · [4.2.5](../objective/D4.2.5.html) Syslog/CEF · [4.2.6](../objective/D4.2.6.html) Windows/WEF · [4.2.7](../objective/D4.2.7.html) custom tables · [4.2.8](../objective/D4.2.8.html) automation · [4.2.9](../objective/D4.2.9.html) retention · [4.2.10](../objective/D4.2.10.html) Purview Audit

- **Workspace.** Sentinel = solution on a Log Analytics workspace. ==!Can't change region==; with Sentinel, ==!can't change RG/subscription==. Defender for Cloud default workspace ==!hidden== from Sentinel. Azure portal support ends ==@March 31, 2027==.
- **Primary vs secondary.** One primary (only one with ==@Defender XDR correlation==), unlimited secondaries. Onboarding disconnects standalone tenant-wide connectors (Entra ID Protection, MDO, MDCA, MDE, MDI).
- **Cross-workspace.** `workspace("x").Table`; rule spans ≤ 20 workspaces (5 recommended). MSSP: Lighthouse (Azure portal); Defender portal = B2B + **multitenant portal** — ==!Lighthouse/GDAP not for Sentinel data==. Workspace manager = preview, Azure portal only.
- **Content hub.** Solution = package with versions (you update); standalone content self-updates. Install ≠ enable. Updates refresh ==!templates only== — active rules get an **Update** badge. Connectors appear ==!after== installing the solution. Support: Microsoft / Partner / Community. ARM template for automation.

| Connector | Method | Extra need | Table |
|---|---|---|---|
| Azure Activity | Policy diagnostic settings | ==@Owner== on scope; disconnect legacy first | `AzureActivity` |
| Entra ID | Entra diagnostic settings | Security Administrator; ==!P1/P2 for sign-ins== | `SigninLogs`, `AuditLogs`, `AAD*` |
| Entra ID Protection | API | Security Administrator, P2 | ==!`SecurityAlert` only== |
| Microsoft 365 | API | Security Administrator, same tenant | `OfficeActivity` |
| Resource diagnostics | Policy diagnostic settings | Owner on scope | `AzureDiagnostics` / resource tables |

Policy connectors: ==!no remediation task = new resources only==. Green status = data in last 14 days.

| Collection | Table | Key facts |
|---|---|---|
| ==@Syslog via AMA== | `Syslog` | needs parser |
| ==@CEF via AMA== | `CommonSecurityLog` | parsed columns; Linux 64-bit forwarder, Arc if off-Azure; ==@514== in, ==@28330== daemon → AMA; ~10,000 EPS; run installer script; ==!same facility in both DCRs = double billing== |
| Windows Security Events via AMA | `SecurityEvent` | All (==!no System/Application==) / Common (has 4634) / Minimal (==!no 4634==) / Custom XPath (1.0, 20 per box, 100 boxes); plain Azure Monitor DCR → ==!`Event`== |
| Windows Forwarded Events (WEF) | ==@`WindowsEvent`== | AMA ==+on WEC only==; NETWORK SERVICE in Event Log Readers; ==!can't enable audit policy==; ~3,000 EPS; use ASIM |

Minimum level = that level ==+and worse==. DCR may sit anywhere in the same tenant. MMA deprecated 31 August 2024.

**Custom tables.** Name `_CL` (==!portal adds it, CLI/REST/Bicep don't==); custom columns on built-in tables `_CF`. `TimeGenerated` mandatory. Logs Ingestion API: app registration → DCR → ==+Monitoring Metrics Publisher on the DCR== (≤ 30 min, else 403). DCE ==!only for private link / older DCRs==. Schema edit ==!doesn't update the DCR==. HTTP Data Collector API = ==!legacy==. Plan change once per table per week.

**Automation.** Triggers: incident created / updated / alert created (==!alert = Run playbook only==). Conditions AND; groups for OR. ==@Lower order first==; same number = ==!random==. **Expiration** for pen-test noise. Playbook trigger must match rule trigger; **entity** trigger manual only. Rule waits 2 min. Consumption (default, templates) vs Standard (single-tenant, VNet, Stateful, no templates). Health: `SentinelHealth` (free), `SentinelAudit` (billed).

| Tier / plan | Query | Retention |
|---|---|---|
| Analytics | full KQL, rules | ==@90 days free== (Sentinel), max ==@2 years== |
| Basic | per-GB scan, 30-day window | total ≤ 12 y |
| Auxiliary / ==@data lake tier== | per-GB, slow; ==!no rules or advanced hunting== | ≤ 12 y |
| Total retention | — | max ==@12 years (4,383 days)== |
| XDR default (advanced hunting) | — | 30 days |

Restore → `_RST` (==!not Auxiliary==, min 2 days); search job → `_SRCH` (all plans). Shortening total retention: ==@30-day wait==. "Archive" ==!is an old name== → long-term retention. Free ingestion (`AzureActivity`, `OfficeActivity`) ≠ free storage past 90 days. Data lake onboarding: once per tenant, primary workspace in Defender portal, ==@direct subscription Owner==.

**Purview Audit.** Defender **Audit** page = ==!same Purview log==. Standard 180 days (90 before 17 Oct 2023); Premium 1 year (Entra/Exchange/OneDrive/SharePoint, E5 users); 10-year add-on ==!not retroactive==; non-user records fixed 1 year; ≤ 50 retention policies. Search: 10 jobs/user, kept 30 days, export 50,000 / 1,000,000 rows. `CloudAppEvents` ==!only if MDCA Microsoft 365 connector== (30 days); `OfficeActivity` via Sentinel connector (long-term KQL, alerts). `CopilotActivity` = separate Microsoft Copilot connector.

## Traps → truth

- Foundational CSPM has attack paths → ==!no==, Defender CSPM.
- Severity = risk level → ==!no==; risk is per resource and context.
- Empty attack paths = broken → ==!no==; check Owner-enabled agentless scanning.
- Each framework scans separately → ==!no==, same recommendations.
- HIPAA for GCP → ==!not built in==; custom standard.
- Servers P2 on three VMs only → ==!no==; subscription-level, P2 can only be disabled per resource.
- Disabling a plan removes agents → ==!no==.
- On-prem connector → ==!no==; Arc.
- New AWS plan works immediately → ==!no==; update the stack.
- Disable rules for accepted CVEs → ==!deprecated==; exemptions.
- Private IP as EASM seed → ==!no==.
- Move Sentinel workspace to another region → ==!recreate==.
- Secondary workspace gets XDR incidents → ==!no==, primary only.
- Sentinel Contributor creates playbooks → ==!no==, Logic App Contributor.
- Automation Contributor for a person → ==!never==.
- Alert-trigger rule changes severity → ==!no==.
- Firewall runs AMA → ==!no==; Linux forwarder.
- WEF events in `SecurityEvent` → ==!no==, `WindowsEvent`.
- App 403 on ingestion → ==+Monitoring Metrics Publisher on the DCR==.
- Analytics retention 12 years → ==!no==, 2; total 12.
- Restore an Auxiliary table → ==!no==; search job.
- Defender Audit page has its own retention → ==!no==, Purview.
- Move Copilot workspace geo → ==!no==; new workspace.
- Copilot contributor reads Sentinel → ==!only with Sentinel Reader==.
- Removing a Store agent stops billing → ==!no==.
