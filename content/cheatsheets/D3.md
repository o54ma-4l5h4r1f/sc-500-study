# D3 — Secure compute (20–25%)

## D3.1 AI security — which tool, which portal

|---|---|---|---|

**Oversharing.** RCD (*Restrict content from Microsoft Copilot*) = ==+hide from Copilot and org search, permissions unchanged==, content stays indexed. RAC = only ≤10 groups open the site (membership ==!doesn't grant== access). DLP for the Copilot location = stop summarising labelled items. Item-level fix = ==+site owner== via site access review (≤100 sites per web batch). Default data risk assessment = ==@top 100 sites, weekly==. Restricted SharePoint Search ==!retiring== → RCD.

**DSPM prerequisites.** Copilot: Audit on + Copilot licences. Security Copilot/Fabric prompts: ==@collection policy== (==!audit alone = no prompt text==). Third-party AI sites: onboarded devices + Purview browser extension. ==!DSPM watches, DLP blocks.== Data after 24 h.

**Real-time protection.** Generative-orchestration agents ==!only==; ==!per environment==; timeout 1 s → default ==!allow== (set *Block the query*). App ID = Defender connection, ==!not the agent ID==. Default rule ==!audits==; custom rules block. No incidents → Microsoft 365 connector missing. Hunt in `BehaviorInfo`.

**CA for agents.** OBO → target ==@users/groups==; app-only → ==@agent identity / blueprint==; agent user → ==@agent users== (not "All users"). Grant = ==!Block only==. Blueprint policy covers future agents, ==!not agent users==. No CA for API keys or blueprint creation.

**Agent ID.** Sponsor ==@required==, can disable ==!not re-enable==; owners ==!not groups==. Access packages: groups, API permissions, Entra roles — ==!not app/SharePoint roles==. Inactivity: notify ==@60== · disable ==@90== · delete ==@455== days. Disable blueprint = all children.

**AI Gateway (APIM).** `llm-token-limit` / `azure-openai-token-limit`: per-minute → ==@429==, quota → ==@403==. `llm-content-safety` (+`shield-prompt`) → 403; threshold ==!0 = strictest==. Foundry *Create new* = ==@Basic v2==; resource-level; ==!existing projects must be added==. Semantic cache = embeddings deployment + Redis. Logs: `ApiManagementGatewayLogs`. ==!Standalone `aigateways` preview ≠ this.==

**Defender for AI Services.** Per subscription, GA, ==!text only==, ==!no AWS==. Prompt evidence off = text masked, ==!detection still on==. Data security for AI interactions = ==!paid Purview==. Foundry ==!agent== detection → Agent 365 from July 1, 2026; models stay.

**Guardrails.** Levels: Low (high only) → ==@High = strictest==. DefaultV2: harms Medium, prompt shields on input, protected material on output, ==!indirect attacks off==. Agents: ==!annotate-and-block only==, tool call/response (preview). Groundedness/Spotlighting = ==!models only==. Hosted agent without `rai_config` = ==!no agent guardrail==. Guardrail policy = Azure Policy. Portal: Foundry **Build > Guardrails**; ARM `raiPolicies`.

**Dashboard.** AI tiles: ==@prompts scanned== (from Defender for AI Services). Full view = Defender CSPM + sensitive data discovery + Storage + Databases + AI services; register `Microsoft.Security`. AI-BOM is CSPM, covers ==@Bedrock and Vertex AI==. Foundry agents ==!no longer shown== → Defender **Assets > AI agents**.

**Agent 365 registry.** Reject (never published) · Block (reversible, org-wide) · Delete (==@30-day== restore). Approval ==!≠ everyone== — scope users. Ownerless → *Assign new owner*.

## D3.2 Servers and VMs

| Encryption | Temp disk | Caches | Key control | Pick when |
|---|---|---|---|---|
| SSE (default, PMK) | ==!No== | No | DES (CMK) | baseline |
| ==+Encryption at host== | Yes (==!PMK only==) | Yes | DES | ==+"encrypt everything"== |
| ADE (BitLocker/DM-Crypt) | Yes | Yes | KEK | ==!retires Sep 15, 2028== |
| Confidential disk encryption | opt-in | Yes | DES | ==@OS disk only==, CVM |

DES: same ==@region== as disks, vault soft delete + purge protection, RSA 2048/3072/4096, identity needs get/wrapKey/unwrapKey. Key gone → ==!VM shuts down==. Encryption at host: register `EncryptionAtHost`, deallocate, ==!never on an ex-ADE VM==; ==!no in-place ADE migration== — new disks, new VM.

| Bastion | Developer | Basic | Standard | Premium |
|---|---|---|---|---|
| Peered VNets | ==!No== | Yes | Yes | Yes |
| Native client, shareable link, IP-based | No | No | ==@Yes== | Yes |
| Session recording, private-only | No | No | No | ==@Yes== |

`AzureBastionSubnet`, ==@/26+==, Standard static public IP, no UDR; NSG optional but needs all 8 rules (443 from Internet/GatewayManager/AzureLoadBalancer, 8080/5701). Upgrade only (==!no downgrade==). Private-only ==!can't be converted== — redeploy. Shareable link holds ==!no credentials==. Recording ==!skips native-client sessions==.

**JIT** ([D3.2.3](../objective/D3.2.3.html)): ==@Servers Plan 2==, NSG or Classic-rules Firewall (==!not Firewall Policy==). Existing allow rule ==!wins==. Max 5 min–1 day (VM blade: 3 h). ==!No approval queue== (use PIM). Open sessions ==!not cut==. Policy = AuditIfNotExists. Activity log 90 days. ==!No JIT on Arc.==

**Arc** ([D3.2.4](../objective/D3.2.4.html)): outbound 443; ==!not on Azure VMs==. SP onboarding = ==@Azure Connected Machine Onboarding==. `azcmagent config` allow list = ==+local veto even Owner can't override==; monitor mode ==!disables machine configuration==. Lists don't uninstall; delete always allowed.

| Defender for Servers | P1 | P2 |
|---|---|---|
| MDE EDR, agent-based MDVM | Yes | Yes |
| Agentless scan, JIT, FIM, OS baseline, 500 MB/day | ==!No== | ==+Yes== |
| Enable on one resource | ==+Yes== | ==!No== |

Default when toggled On = ==@P2==. 30-day trial ==!can't pause==. AWS/GCP: connector auto-provisions Arc (Owner + SSM / OS Config agent). Direct onboarding = P1 + subset, ==!no Policy/Machine Configuration==. 500 MB = enable P2 ==@on the workspace== too.

**Settings** ([D3.2.6](../objective/D3.2.6.html)): Endpoint protection On (MDE.Windows/Linux); MDVM On; agentless On (P2); ==!FIM Off== until you pick a workspace (MDE-based, 500 rules). Qualys/BYOL ==!retired==. Both agent and agentless → ==@agent-based== shown.

**Agentless** ([D3.2.7](../objective/D3.2.7.html)): P2 or ==@Defender CSPM==; malware ==!P2 only==; 24 h fixed; running VMs only; ≤14 disks, 4 TB; Ultra/PremiumV2 → skipped. CMK → scanner app needs ==@Key Vault Crypto Service Encryption User==. Exclude by tag.

**Trusted launch** ([D3.2.8](../objective/D3.2.8.html)): Gen2, free, Secure Boot + vTPM; integrity monitoring = separate tick, Guest Attestation + ==@AzureAttestation== outbound. vTPM off → monitoring off. Bootkits → Trusted launch; data in use → ==+Confidential VM== (create-time only). Gen1 → Gen2 + Trusted launch together (MBR2GPT); rollback to Standard is ==!one-way==. ==!Managed Images unsupported== → Compute Gallery.

**Machine Configuration** ([D3.2.9](../objective/D3.2.9.html)): Azure VM = extension + ==@system-assigned identity== (initiative + ==!remediation task==); Arc = built into agent. `Audit` · `ApplyAndMonitor` (reports drift) · ==+`ApplyAndAutoCorrect`==. Baselines audit-only; ==!`IncludeArcMachines` defaults false==. 50 assignments/machine.

## D3.3 Application platform

**Defender for Containers** ([D3.3.1](../objective/D3.3.1.html)): sensor (runtime), Azure Policy add-on (==+Deny at admission==), agentless nodes, K8s API access (runtime VA, any registry), registry access. Attack paths need ==!Defender CSPM==. Drift blocking ==!preview==. First enable: ==@Owner or UAA==.

**AKS** ([D3.3.2](../objective/D3.3.2.html)): Entra integration ==!keeps local accounts== → `--disable-local-accounts` (admin group first). Cluster User Role = download kubeconfig, ==!no rights==. Private cluster ==!or== authorized IPs (≤200), not both. Windows network policy → ==+Calico==; Azure NPM legacy. Workload ID + Key Vault CSI. Kubernetes Secrets = ==!base64==.

**ACR** ([D3.3.3](../objective/D3.3.3.html)): admin user off. ABAC mode ==!ignores AcrPull/AcrPush==. Tokens ==!aren't Entra==. Private endpoint, IP rules (200) = ==@Premium==. Anonymous pull = ==!registry-wide==. DCT ==!no new enablement since May 31, 2026== → Notation.

**ACI / Container Apps** ([D3.3.4](../objective/D3.3.4.html)): ACI ACR pull = ==@user-assigned only==; `secureValue`; VNet = ==!no public IP==. ACA: internal ingress; IP rules ==!all allow or all deny==; Key Vault refs refresh ==@30 min== (App Service/Functions ==@24 h==); peer-to-peer encryption ==!off by default==.

| App front-door feature | What it does | Gotcha |
|---|---|---|
| Access restrictions | filter public inbound (IP, service tag, subnet) | ==!skip private endpoint traffic==; SCM needs own rules |
| Private endpoint | private inbound IP | ==!no outbound== |
| VNet integration | outbound to private resources | ==!app stays public== |
| Easy Auth | Entra sign-in before code | any tenant user unless *Assignment required* |
| Function keys | shared secret | ==!not identity==; Node v4 default anonymous |
| APIM `validate-azure-ad-token` | Entra token check inbound | prefer over `validate-jwt` for Entra |

**Functions** ([D3.3.5](../objective/D3.3.5.html)): private endpoint/VNet integration ==!not on Consumption== → Flex/Premium/Dedicated. Master key opens `/admin`. CORS ==!isn't server-side control==.

**Logic Apps** ([D3.3.6](../objective/D3.3.6.html)): private networking = ==@Standard==. OAuth policy (issuer + audience), disable SAS; ==!one scheme per call==. Leaked URL → regenerate keys. Secure inputs/outputs ==!per action==.

**App Service** ([D3.3.7](../objective/D3.3.7.html)): HTTPS Only, TLS 1.2 default, FTPS only/off, basic-auth publishing off (default for new). Front Door lock = service tag ==+plus `X-Azure-FDID`==. Client certs: ==!app validates==. Dangling DNS → Defender for App Service.

**WAF** ([D3.3.8](../objective/D3.3.8.html)): App Gateway = regional; Front Door = global, managed rules ==!Premium only==. Detection default (==!never blocks==). Anomaly score ==@≥5== blocks (rule 949110). Custom rules first; Allow stops evaluation. Exclusions ==+per rule==, ==!not global==. Per-URI > per-site > global.

**APIM** ([D3.3.9](../objective/D3.3.9.html)): `rate-limit` → ==@429==, `quota` → ==@403==. Backend: ==+`authentication-managed-identity`==, then lock backend to APIM. ==!Standard v2 VNet integration leaves gateway public==; internal = Developer/Premium or Premium v2 injection. Defender for APIs = enable plan ==+and onboard APIs==.
